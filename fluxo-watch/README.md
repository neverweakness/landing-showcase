# Fluxo Watch

Лендинг умных часов с предзаказом.

**Демо:** https://neverweakness.github.io/landing-showcase/fluxo-watch/

- 3D-рендеры часов из Blender в 4 цветах и 5 ракурсах (WebP)
- Вращение по ракурсам, смена цвета
- Светлая и тёмная темы
- Форма предзаказа

Демо-проект для портфолио: бренд, цены и тексты вымышлены. Один файл `index.html`, без зависимостей.
