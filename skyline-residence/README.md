# Skyline Residence

Лендинг жилого комплекса бизнес-класса.

**Демо:** https://neverweakness.github.io/landing-showcase/skyline-residence/

- Герой: сумеречный город из SVG с огнями окон и параллаксом, стеклянная башня комплекса
- Подбор квартир: планировки, фильтр по комнатам и бюджету, сортировка
- Блок «Вид с этажа»: ползунок этажа и время суток перестраивают сцену
- Ипотечный калькулятор на range-слайдерах
- Бронирование в `<dialog>`: маска телефона, проверка, номер брони

Демо-проект для портфолио: бренд, цены и тексты вымышлены. Один файл `index.html`, без зависимостей.
