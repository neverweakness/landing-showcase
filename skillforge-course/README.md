# SkillForge

Лендинг онлайн-курса по Python.

**Демо:** https://neverweakness.github.io/landing-showcase/skillforge-course/

- Тёмный дизайн, canvas-анимация
- Программа курса, таймер скидки, тарифы с переключателем оплаты и рассрочки
- Демо-окно оплаты на `<dialog>`

Демо-проект для портфолио: бренд, цены и тексты вымышлены. Один файл `index.html`, без зависимостей.
