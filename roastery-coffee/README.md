# Roastery 04

Лендинг кофейни с подпиской.

**Демо:** https://neverweakness.github.io/landing-showcase/roastery-coffee/

- Иллюстрации зёрен, воронки V60, эспрессо и четырёх пачек нарисованы SVG
- Конфигуратор подписки: сорт, граммовка, помол, частота; цена и скидки пересчитываются сразу
- Слои `@layer`, контейнерные запросы, scroll-driven анимация
- Оформление с проверкой полей

Демо-проект для портфолио: бренд, цены и тексты вымышлены. Один файл `index.html`, без зависимостей.
