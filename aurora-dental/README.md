# Aurora Dental

Лендинг стоматологической клиники с онлайн-записью.

**Демо:** https://neverweakness.github.io/landing-showcase/aurora-dental/

- Split-экран: закреплённая панель слева и прокручиваемый контент
- Калькулятор плана лечения с рассрочкой
- Слайдер «до/после» на одном range и `clip-path`
- Отзывы с аватарами-смайликами и рейтингом
- Мастер записи в 4 шага: календарь на 14 дней, слоты, живая сводка, экспорт в календарь (.ics)

Демо-проект для портфолио: бренд, цены и тексты вымышлены. Один файл `index.html`, без зависимостей.
